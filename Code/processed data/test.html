Paragraphs:
Introduction, Global Overview, Land Use Efficiency, Second visualization

Introduction

In 1961, China was still a country marked by hunger: the population was growing fast, but the fields were not enough. In sixty years, however, the way the country provides food for its people has changed radically.
This project aims to offer viewers an insight into China’s extraordinary agricultural evolution and its powerful strategies for confronting one of humanity’s greatest challenge: global hunger.
